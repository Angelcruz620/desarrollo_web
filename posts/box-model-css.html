Cómo funciona el modelo de caja (Box Model) en CSS

31 de marzo, 2026

Cuando empecé a aprender CSS, los elementos nunca quedaban donde yo quería. Entender el Box Model fue lo que cambió todo. En este post te explico cómo funciona desde cero.

¿Qué es el Box Model?

En CSS, cada elemento HTML es tratado como una caja rectangular. No importa si es un título, un párrafo o un botón — todos son cajas. El Box Model describe las capas que forman esa caja:

  • Content — el contenido real (texto, imagen, etc.)
  • Padding — espacio entre el contenido y el borde
  • Border — el borde que rodea el padding
  • Margin — espacio entre este elemento y los demás

Visualmente, las capas van de adentro hacia afuera así:

Margin
Border
Padding
Content

Las 4 capas en código

Así se escribe cada capa en CSS:

.mi-caja {
  /* 1. El tamaño del contenido */
  width: 200px;
  height: 100px;

  /* 2. Espacio interno (padding) */
  padding: 16px;

  /* 3. El borde */
  border: 2px solid #2563eb;

  /* 4. Espacio externo (margin) */
  margin: 24px;
}

El problema más común al empezar

Imagina que defines una caja con width: 200px y le agregas padding: 20px. ¿Cuánto mide tu caja en total?

Por defecto en CSS, el padding se suma al ancho. Entonces tu caja mide en realidad 240px (200 + 20 de cada lado). Esto confunde a todos al principio. 

/* ❌ Sin box-sizing: la caja mide 240px de ancho */
.caja {
  width: 200px;
  padding: 20px;
}

/* ✅ Con box-sizing: la caja mide exactamente 200px */
.caja {
  width: 200px;
  padding: 20px;
  box-sizing: border-box;
}

La solución: box-sizing: border-box

Con border-box le dices al navegador que el width que defines incluye el padding y el border. El contenido se reduce para que todo quepa exactamente en el tamaño que pediste.

Es tan útil que la mayoría de desarrolladores lo aplican a todos los elementos del sitio desde el inicio, con este truco en el CSS: 

/* Esto va al inicio de tu style.css */
* {
  box-sizing: border-box;
}

De hecho, si mirás el style.css que construimos para este blog, esa línea ya está en el reset básico. 😉

Margin vs Padding — ¿cuándo usar cada uno?

Una regla simple para no confundirte:

Padding

Espacio dentro del elemento. Afecta el fondo y el borde.

Úsalo cuando quieras que el contenido tenga aire adentro.

Margin

Espacio fuera del elemento. Separa elementos entre sí.

Úsalo para separar un elemento de sus vecinos.

Conclusión

El Box Model es uno de esos conceptos que una vez que entendés, todo en CSS empieza a tener sentido. Recordá siempre: content → padding → border → margin, de adentro hacia afuera.

Y agregá box-sizing: border-box al inicio de todo proyecto — te va a ahorrar muchos dolores de cabeza.
