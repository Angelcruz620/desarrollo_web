Hola, soy Angel Cruz 👋

Aprendiendo desarrollo web, un proyecto a la vez.

¿Quién soy?

Soy una persona apasionada por el desarrollo web, actualmente en proceso de aprendizaje. Este blog nació como una forma de documentar mi camino: los conceptos que aprendo, los errores que cometo y las soluciones que encuentro.

Creo que explicar lo que aprendes es la mejor forma de afianzarlo — así que si estás también empezando, este es un buen lugar para acompañarnos.

¿Qué estoy aprendiendo?

🌐 HTML La estructura de toda página web
🎨 CSS Estilos, diseño y responsive
⚡ JavaScript Interactividad en el navegador
🐍 Python Automatización y scripting

¿Por qué este blog?

Cuando empiezas a aprender programación, encontrar recursos en español claros y honestos no siempre es fácil. Quiero que este blog sea ese recurso: sin pretender saber todo, compartiendo el proceso real de aprender.
